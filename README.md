# Grand Réseau

Jeu de gestion du trafic dans le navigateur. Reliez les villes d'une région, améliorez les routes (chemin, route, nationale, autoroute), posez des péages et des radars, gérez les bouchons, les accidents et le budget.

**Jouer :** https://thibut34.github.io/grand-reseau/

- `index.html` : version 3D
- `classique.html` : version 2D

## Commandes

| Action | Commande |
| --- | --- |
| Tracer / améliorer une route | Glisser avec un outil route (1 à 4) |
| Tracé droit | Maj + glisser |
| Déplacer la carte | Clic droit, ZQSD ou flèches |
| Tourner la vue | Clic molette, A / E |
| Zoom | Molette |
| Péage · Radar · Démolir | T · R · B |
| Inspecter | I |
| Bouchons | H |
| Pause | Espace |

La partie est sauvegardée automatiquement chaque nuit dans le navigateur.
